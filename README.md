# Codence AI

Codence AI is a PHP-based web application for showcasing digital
services and managing users, services, contact messages, and
consultation bookings.

## Features

### User Website

-   Home page
-   About Us
-   Services
-   Contact
-   User registration and login
-   User profile
-   Service booking
-   Contact form

### Admin Panel

-   Dashboard
-   User management
-   Service management
-   Booking management
-   Booking status updates
-   Contact message management

### Booking Status

-   Pending
-   Confirmed
-   Completed
-   Cancelled

## Technology Stack

-   PHP
-   HTML5
-   CSS3
-   JavaScript
-   MySQL
-   phpMyAdmin
-   Laragon

## How to Run

1.  Install **Laragon** and start Apache and MySQL.
2.  Place the project inside: `C:\laragon\www\`
3.  Create the required MySQL database using **phpMyAdmin**.
4.  Import the database SQL file, if included.
5.  Configure the database connection in the project.
6.  Open the website:

``` text
http://localhost/codence-ai/
```

Admin panel:

``` text
http://localhost/codence-ai/admin/dashboard.php
```

## Project Purpose

The goal of Codence AI is to provide a simple and professional platform
where users can explore digital services and submit consultation
requests, while administrators can manage the website content and
incoming requests from one place.
